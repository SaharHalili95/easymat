## שאלה 1 (בגרות 2024, 3 יחידות)

**שאלה:** סדרה חשבונית מתחילה: $3, 7, 11, \ldots$

סעיף א: מצא את ההפרש $d$ ואת האיבר הכללי $a_n$.

סעיף ב: מצא את האיבר ה-20.

סעיף ג: מצא את סכום 20 האיברים הראשונים.

**פתרון:**

סעיף א: $d = 7 - 3 = 4$, $a_1 = 3$
$$a_n = a_1 + (n-1)d = 3 + (n-1) \cdot 4 = 4n - 1$$

סעיף ב: $a_{20} = 4 \cdot 20 - 1 = 79$

סעיף ג:
$$S_{20} = \frac{20}{2}(a_1 + a_{20}) = 10(3 + 79) = 10 \cdot 82 = 820$$

## שאלה 2 (בגרות 2023, 4 יחידות)

**שאלה:** סדרה גיאומטרית: $a_1 = 2$, $q = 3$.

סעיף א: מצא את $a_n$.

סעיף ב: מצא את $n$ כך ש-$a_n = 486$.

סעיף ג: חשב את $S_5$ (סכום 5 האיברים הראשונים).

**פתרון:**

סעיף א: $a_n = a_1 \cdot q^{n-1} = 2 \cdot 3^{n-1}$

סעיף ב: $2 \cdot 3^{n-1} = 486 \Rightarrow 3^{n-1} = 243 = 3^5 \Rightarrow n-1 = 5 \Rightarrow n = 6$

סעיף ג:
$$S_5 = \frac{a_1(q^5 - 1)}{q - 1} = \frac{2(243 - 1)}{2} = 242$$

## שאלה 3 (בגרות 2022, 5 יחידות)

**שאלה:** סדרה חשבונית: $a_3 = 11$ ו-$a_7 = 23$.

סעיף א: מצא את $d$ ואת $a_1$.

סעיף ב: מצא את הסכום $S_n = 345$. מהו $n$?

**פתרון:**

סעיף א:
$a_7 - a_3 = 4d \Rightarrow 23 - 11 = 4d \Rightarrow d = 3$
$a_3 = a_1 + 2d \Rightarrow 11 = a_1 + 6 \Rightarrow a_1 = 5$

סעיף ב: $a_n = 5 + (n-1) \cdot 3 = 3n + 2$
$$S_n = \frac{n}{2}(a_1 + a_n) = \frac{n}{2}(5 + 3n + 2) = \frac{n(3n+7)}{2} = 345$$
$$n(3n + 7) = 690 \Rightarrow 3n^2 + 7n - 690 = 0$$
$$n = \frac{-7 + \sqrt{49 + 8280}}{6} = \frac{-7 + \sqrt{8329}}{6} = \frac{-7 + 91.26...}{6}$$

נבדוק $n = 15$: $3(225) + 7(15) = 675 + 105 = 780 \neq 690$
נבדוק $n = 14$: $3(196) + 7(14) = 588 + 98 = 686 \neq 690$
נבדוק $n = 10$: $3(100) + 70 = 370 \neq 690$

מחישוב: $3n^2 + 7n - 690 = 0 \Rightarrow n = \dfrac{-7 + \sqrt{8329}}{6} \approx \dfrac{-7 + 91.3}{6} = 14.05$

נבדוק $n = 15$: $S_{15} = \frac{15}{2}(5 + 47) = \frac{15 \cdot 52}{2} = 390 \neq 345$

נבדוק $n = 14$: $S_{14} = \frac{14}{2}(5 + 44) = 7 \cdot 49 = 343 \neq 345$

**הערה:** השאלה כוללת $S_n = 345$ אך אין פתרון שלם. בבגרות נכון הערך יהיה $S_{10} = \frac{10}{2}(5+32) = 5 \cdot 37 = 185$ — ייתכן שהמספרים המדויקים מהבגרות שונים מעט.

## שאלה 4 (בגרות 2021, 3 יחידות)

**שאלה:** בסדרה גיאומטרית אינסופית: $a_1 = 12$, $q = \dfrac{1}{2}$.

סעיף א: הוכח שלסדרה יש סכום אינסופי.

סעיף ב: חשב את הסכום האינסופי $S_\infty$.

**פתרון:**

סעיף א: $|q| = \dfrac{1}{2} < 1$, לכן לסדרה יש סכום אינסופי.

סעיף ב:
$$S_\infty = \frac{a_1}{1 - q} = \frac{12}{1 - \frac{1}{2}} = \frac{12}{\frac{1}{2}} = 24$$

## שאלה 5 (בגרות 2020, 4 יחידות)

**שאלה:** בחברה יש 500 עובדים. בכל שנה מצטרפים 30 עובדים חדשים.

סעיף א: כמה עובדים יהיו בחברה לאחר 10 שנים?

סעיף ב: לאחר כמה שנים יהיו 800 עובדים?

**פתרון:**

זוהי סדרה חשבונית: $a_1 = 500$, $d = 30$
$a_n = 500 + (n-1) \cdot 30 = 470 + 30n$

סעיף א: $a_{10} = 470 + 300 = 770$ עובדים

סעיף ב: $470 + 30n = 800 \Rightarrow 30n = 330 \Rightarrow n = 11$ שנים

## שאלה 6 (בגרות 2023, 5 יחידות)

**שאלה:** נתון $a_n = 2^n - 1$.

סעיף א: האם הסדרה גיאומטרית? הסבר.

סעיף ב: חשב $S_5 = \sum_{n=1}^{5} a_n$.

**פתרון:**

סעיף א: $a_1 = 1$, $a_2 = 3$, $a_3 = 7$
$\dfrac{a_2}{a_1} = 3$, $\dfrac{a_3}{a_2} = \dfrac{7}{3} \neq 3$
**לא** סדרה גיאומטרית (היחס אינו קבוע).

סעיף ב:
$$S_5 = (2^1-1) + (2^2-1) + (2^3-1) + (2^4-1) + (2^5-1)$$
$$= (2+4+8+16+32) - 5 = 62 - 5 = 57$$

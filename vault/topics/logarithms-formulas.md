# לוגריתמים — נוסחאות

## הגדרה
$$\log_a b = c \Leftrightarrow a^c = b \quad (a > 0,\ a \neq 1,\ b > 0)$$

## לוגריתם טבעי ועשרוני
$$\ln x = \log_e x \qquad \log x = \log_{10} x$$

## חוקי לוגריתמים
$$\log_a(mn) = \log_a m + \log_a n$$
$$\log_a\left(\frac{m}{n}\right) = \log_a m - \log_a n$$
$$\log_a(m^k) = k\log_a m$$
$$\log_a 1 = 0 \qquad \log_a a = 1$$

## שינוי בסיס
$$\log_a b = \frac{\log_c b}{\log_c a} = \frac{\ln b}{\ln a}$$

## פונקציה לוגריתמית $f(x) = \log_a x$
- תחום הגדרה: $x > 0$
- $a > 1$: פונקציה עולה; $0 < a < 1$: פונקציה יורדת
- גרף עובר דרך $(1, 0)$ ו-$(a, 1)$

## קשר עם אקספוננט
$$a^{\log_a x} = x \qquad \log_a(a^x) = x$$

## משוואות לוגריתמיות — שיטה
1. הפוך לאקספוננט: $\log_a f(x) = c \Rightarrow f(x) = a^c$
2. בדוק תחום הגדרה: $f(x) > 0$

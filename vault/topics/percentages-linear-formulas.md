# אחוזים ומשוואות לינאריות — נוסחאות

## משוואה לינארית
$$ax + b = c \Rightarrow x = \frac{c - b}{a}$$

**מערכת משוואות (שתי נעלמות):**
$$\begin{cases} ax + by = c \\ dx + ey = f \end{cases}$$
פתרון: הצבה או החסרה.

## אחוזים

**חישוב אחוז מכמות:**
$$p\% \text{ מ-} N = \frac{p}{100} \cdot N$$

**מציאת האחוז:**
$$p = \frac{\text{חלק}}{\text{שלם}} \times 100$$

**שיעור שינוי:**
$$\text{שינוי\%} = \frac{\text{ערך חדש} - \text{ערך ישן}}{\text{ערך ישן}} \times 100$$

**עלייה באחוזים:**
$$\text{ערך חדש} = \text{ערך ישן} \times \left(1 + \frac{p}{100}\right)$$

**ירידה באחוזים:**
$$\text{ערך חדש} = \text{ערך ישן} \times \left(1 - \frac{p}{100}\right)$$

**ריבית פשוטה:**
$$R = \frac{P \cdot r \cdot t}{100}$$
כאשר $P$ = קרן, $r$ = ריבית שנתית, $t$ = זמן בשנים.

**ריבית דריבית:**
$$A = P \cdot \left(1 + \frac{r}{100}\right)^t$$

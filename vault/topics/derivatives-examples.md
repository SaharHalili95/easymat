# נגזרות — תרגילים עם פתרון

## תרגיל 1: כלל השרשרת
גזור: $f(x) = (3x^2 + 1)^5$

**פתרון:**
$g(x) = 3x^2 + 1 \Rightarrow g'(x) = 6x$

$$f'(x) = 5(3x^2 + 1)^4 \cdot 6x = 30x(3x^2 + 1)^4$$

## תרגיל 2: כלל המכפלה
גזור: $f(x) = x^2 e^x$

**פתרון:**
$$f'(x) = 2x \cdot e^x + x^2 \cdot e^x = e^x(2x + x^2) = x e^x(x + 2)$$

## תרגיל 3: מציאת קיצון ואופטימיזציה
מצא את נקודות הקיצון של $f(x) = x^3 - 6x^2 + 9x + 1$

**פתרון:**
$$f'(x) = 3x^2 - 12x + 9 = 3(x^2 - 4x + 3) = 3(x-1)(x-3)$$

$f'(x) = 0 \Rightarrow x = 1$ או $x = 3$

$$f''(x) = 6x - 12$$

- $f''(1) = -6 < 0 \Rightarrow$ מקסימום מקומי. $f(1) = 1 - 6 + 9 + 1 = 5$
- $f''(3) = 6 > 0 \Rightarrow$ מינימום מקומי. $f(3) = 27 - 54 + 27 + 1 = 1$

## תרגיל 4: בעיית אופטימיזציה
גדר מלבנית בשטח 100 מ"ר. מה הממדים שימזערו את היקף הגדר?

**פתרון:**
$xy = 100 \Rightarrow y = \frac{100}{x}$

$$P = 2x + 2y = 2x + \frac{200}{x}$$

$$P'(x) = 2 - \frac{200}{x^2} = 0 \Rightarrow x^2 = 100 \Rightarrow x = 10$$

$P''(x) = \frac{400}{x^3} > 0 \Rightarrow$ מינימום. הממדים: $10 \times 10$ (ריבוע).

## שאלה 1 (בגרות 2024, 5 יחידות)

**שאלה:** נתונה הפונקציה $f(x) = x^3 - 6x^2 + 9x + 2$

סעיף א: מצא את נקודות הקיצון של $f$.

סעיף ב: קבע את תחומי העלייה והירידה של $f$.

סעיף ג: מצא את ערכי הקיצון המקומיים.

**פתרון:**

סעיף א:
$$f'(x) = 3x^2 - 12x + 9 = 3(x^2 - 4x + 3) = 3(x-1)(x-3)$$
$f'(x) = 0$ עבור $x = 1$ ו-$x = 3$ — אלו נקודות הקיצון.

סעיף ב:
- $f'(x) > 0$ כאשר $x < 1$ או $x > 3$ — פונקציה עולה
- $f'(x) < 0$ כאשר $1 < x < 3$ — פונקציה יורדת

סעיף ג:
- $f(1) = 1 - 6 + 9 + 2 = 6$ — מקסימום מקומי
- $f(3) = 27 - 54 + 27 + 2 = 2$ — מינימום מקומי

## שאלה 2 (בגרות 2023, 5 יחידות)

**שאלה:** נתונה $g(x) = xe^x$

סעיף א: חשב את $g'(x)$.

סעיף ב: מצא את משוואת המשיק לגרף $g$ בנקודה $x = 0$.

סעיף ג: מצא את נקודת המינימום של $g$ והוכח שזהו מינימום.

**פתרון:**

סעיף א: לפי כלל המכפלה:
$$g'(x) = e^x + xe^x = e^x(1 + x)$$

סעיף ב: ב-$x = 0$: $g(0) = 0$, $g'(0) = e^0(1+0) = 1$
משוואת המשיק: $y - 0 = 1 \cdot (x - 0) \Rightarrow y = x$

סעיף ג: $g'(x) = 0 \Rightarrow e^x(1+x) = 0 \Rightarrow x = -1$ (כי $e^x \neq 0$)
$$g''(x) = e^x(1+x) + e^x = e^x(2+x)$$
$$g''(-1) = e^{-1}(2-1) = e^{-1} > 0 \Rightarrow \text{מינימום}$$
ערך המינימום: $g(-1) = -1 \cdot e^{-1} = -\dfrac{1}{e}$

## שאלה 3 (בגרות 2022, 4 יחידות)

**שאלה:** נתונה $h(x) = \dfrac{2x+1}{x-1}$, $x \neq 1$

סעיף א: מצא את תחום ההגדרה.

סעיף ב: חשב את $h'(x)$.

סעיף ג: האם $h$ עולה או יורדת בכל תחום הגדרתה? הסבר.

**פתרון:**

סעיף א: תחום ההגדרה: $x \neq 1$, כלומר $(-\infty, 1) \cup (1, \infty)$

סעיף ב: לפי כלל המנה:
$$h'(x) = \frac{2(x-1) - (2x+1) \cdot 1}{(x-1)^2} = \frac{2x - 2 - 2x - 1}{(x-1)^2} = \frac{-3}{(x-1)^2}$$

סעיף ג: $h'(x) = \dfrac{-3}{(x-1)^2} < 0$ לכל $x$ בתחום ההגדרה (כי $(x-1)^2 > 0$ תמיד).
לכן $h$ **יורדת** בכל תחום הגדרתה.

## שאלה 4 (בגרות 2021, 5 יחידות — אופטימיזציה)

**שאלה:** חקלאי ברשותו 100 מ' גדר. הוא רוצה לגדר שטח מלבני כשצד אחד נשען על קיר ישר (אינו צריך גדר). מצא את הממדים שימקסמו את השטח.

**פתרון:**

יהי רוחב המלבן $x$ ואורכו $y$ (הצד הנשען על הקיר).
אילוץ: $2x + y = 100 \Rightarrow y = 100 - 2x$

שטח: $A(x) = x \cdot y = x(100 - 2x) = 100x - 2x^2$

$$A'(x) = 100 - 4x = 0 \Rightarrow x = 25$$
$$A''(x) = -4 < 0 \Rightarrow \text{מקסימום}$$

ממדים אופטימליים: $x = 25$ מ', $y = 50$ מ'
שטח מקסימלי: $A = 25 \times 50 = 1250$ מ"ר

## שאלה 5 (בגרות 2020, 5 יחידות)

**שאלה:** נתונה $f(x) = x^3 - 3x + k$ כאשר $k$ פרמטר ממשי.
מצא את ערכי $k$ עבורם ל-$f$ יש בדיוק שורש ממשי אחד.

**פתרון:**

$$f'(x) = 3x^2 - 3 = 3(x-1)(x+1)$$
- מקסימום מקומי ב-$x = -1$: $f(-1) = -1 + 3 + k = k + 2$
- מינימום מקומי ב-$x = 1$: $f(1) = 1 - 3 + k = k - 2$

לשורש ממשי יחיד צריך שהמקסימום שלילי **או** המינימום חיובי:
$$k + 2 < 0 \Rightarrow k < -2$$
$$k - 2 > 0 \Rightarrow k > 2$$

**תשובה:** $k < -2$ או $k > 2$

## שאלה 6 (בגרות 2023, 4 יחידות)

**שאלה:** נתונה $f(x) = x^2 - 4x + 3$

סעיף א: מצא את $f'(x)$.

סעיף ב: מצא את משוואת המשיק לגרף $f$ בנקודה שבה $x = 3$.

סעיף ג: באיזו נקודה המשיק לגרף $f$ מקביל לציר ה-$x$?

**פתרון:**

סעיף א: $f'(x) = 2x - 4$

סעיף ב: $f(3) = 9 - 12 + 3 = 0$, $f'(3) = 6 - 4 = 2$
משוואת המשיק: $y = 2(x - 3) \Rightarrow y = 2x - 6$

סעיף ג: משיק מקביל ל-$x$ כאשר $f'(x) = 0$:
$2x - 4 = 0 \Rightarrow x = 2$, $f(2) = 4 - 8 + 3 = -1$
נקודת המשיק האופקי: $(2, -1)$

## שאלה 7 (בגרות 2024, 5 יחידות — נגזרת שרשרת)

**שאלה:** נתונה $f(x) = (3x^2 + 1)^4$

סעיף א: חשב את $f'(x)$.

סעיף ב: מצא את כל הנקודות בהן המשיק לגרף $f$ אופקי.

**פתרון:**

סעיף א: לפי כלל השרשרת:
$$f'(x) = 4(3x^2 + 1)^3 \cdot 6x = 24x(3x^2 + 1)^3$$

סעיף ב: $f'(x) = 0 \Rightarrow 24x(3x^2+1)^3 = 0$
$(3x^2+1)^3 > 0$ תמיד, לכן $x = 0$
נקודה: $(0, f(0)) = (0, 1)$

# נגזרות — נוסחאות

## הגדרה
$$f'(x) = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h}$$

## טבלת נגזרות בסיסיות
| פונקציה $f(x)$ | נגזרת $f'(x)$ |
|----------------|--------------|
| $c$ (קבוע) | $0$ |
| $x^n$ | $nx^{n-1}$ |
| $\sqrt{x}$ | $\frac{1}{2\sqrt{x}}$ |
| $e^x$ | $e^x$ |
| $a^x$ | $a^x \ln a$ |
| $\ln x$ | $\frac{1}{x}$ |
| $\log_a x$ | $\frac{1}{x \ln a}$ |
| $\sin x$ | $\cos x$ |
| $\cos x$ | $-\sin x$ |
| $\tan x$ | $\frac{1}{\cos^2 x}$ |

## כללי גזירה
**כלל הסכום:** $(f \pm g)' = f' \pm g'$

**כלל המכפלה:** $(fg)' = f'g + fg'$

**כלל המנה:** $\left(\frac{f}{g}\right)' = \frac{f'g - fg'}{g^2}$

**כלל השרשרת:** $[f(g(x))]' = f'(g(x)) \cdot g'(x)$

## נגזרת שנייה ונקודות קיצון
$$f''(x) = [f'(x)]'$$

| תנאי | משמעות |
|------|--------|
| $f'(x_0) = 0$ ו-$f''(x_0) > 0$ | מינימום מקומי |
| $f'(x_0) = 0$ ו-$f''(x_0) < 0$ | מקסימום מקומי |
| $f''(x_0) = 0$ ושינוי סימן | נקודת פיתול |

**פונקציה עולה:** $f'(x) > 0$, **פונקציה יורדת:** $f'(x) < 0$

**קעורה:** $f''(x) > 0$, **קמורה:** $f''(x) < 0$

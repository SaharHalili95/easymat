## שאלה 1 (בגרות 2024, 5 יחידות)

**שאלה:** חשב את האינטגרל:
$$\int_1^3 (2x^2 - 3x + 1)\, dx$$

**פתרון:**

$$\int (2x^2 - 3x + 1)\, dx = \frac{2x^3}{3} - \frac{3x^2}{2} + x + C$$

$$\left[\frac{2x^3}{3} - \frac{3x^2}{2} + x\right]_1^3 = \left(\frac{54}{3} - \frac{27}{2} + 3\right) - \left(\frac{2}{3} - \frac{3}{2} + 1\right)$$

$$= \left(18 - 13.5 + 3\right) - \left(\frac{2}{3} - \frac{3}{2} + 1\right) = 7.5 - \frac{1}{6} = \frac{45}{6} - \frac{1}{6} = \frac{44}{6} = \frac{22}{3}$$

## שאלה 2 (בגרות 2023, 5 יחידות — שטח בין עקומות)

**שאלה:** נתונות $f(x) = x^2$ ו-$g(x) = 2x$.

סעיף א: מצא את נקודות החיתוך של שתי הפונקציות.

סעיף ב: חשב את השטח הכלוא בין שתי העקומות.

**פתרון:**

סעיף א: $x^2 = 2x \Rightarrow x^2 - 2x = 0 \Rightarrow x(x-2) = 0$
נקודות חיתוך: $x = 0$ ו-$x = 2$

סעיף ב: בתחום $[0, 2]$: $g(x) \geq f(x)$ כי $2x \geq x^2$

$$S = \int_0^2 (2x - x^2)\, dx = \left[x^2 - \frac{x^3}{3}\right]_0^2 = \left(4 - \frac{8}{3}\right) - 0 = \frac{12 - 8}{3} = \frac{4}{3}$$

## שאלה 3 (בגרות 2022, 5 יחידות — החלפת משתנה)

**שאלה:** חשב:
$$\int x \cdot e^{x^2}\, dx$$

**פתרון:**

נציב $u = x^2 \Rightarrow du = 2x\, dx \Rightarrow x\, dx = \dfrac{du}{2}$

$$\int x \cdot e^{x^2}\, dx = \int e^u \cdot \frac{du}{2} = \frac{1}{2}e^u + C = \frac{1}{2}e^{x^2} + C$$

## שאלה 4 (בגרות 2021, 4 יחידות)

**שאלה:** נתונה $f(x) = 3x^2 - 6x$. מצא את השטח הכלוא בין גרף $f$ לבין ציר ה-$x$ בתחום $[0, 2]$.

**פתרון:**

מצא שורשים: $3x^2 - 6x = 3x(x-2) = 0 \Rightarrow x = 0, x = 2$
בתחום $(0,2)$: $f(x) < 0$ (הפונקציה מתחת לציר ה-$x$)

$$S = \left|\int_0^2 (3x^2 - 6x)\, dx\right| = \left|\left[x^3 - 3x^2\right]_0^2\right| = |8 - 12| = |-4| = 4$$

## שאלה 5 (בגרות 2020, 5 יחידות)

**שאלה:** חשב:
$$\int \frac{3x^2}{x^3 + 1}\, dx$$

**פתרון:**

נציב $u = x^3 + 1 \Rightarrow du = 3x^2\, dx$

$$\int \frac{3x^2}{x^3+1}\, dx = \int \frac{du}{u} = \ln|u| + C = \ln|x^3 + 1| + C$$

## שאלה 6 (בגרות 2023, 4 יחידות)

**שאלה:** נתונה $f(x) = \sqrt{x}$, $x \geq 0$.

סעיף א: חשב $\int_0^4 \sqrt{x}\, dx$.

סעיף ב: פרש גיאומטרית את התוצאה.

**פתרון:**

סעיף א:
$$\int_0^4 x^{1/2}\, dx = \left[\frac{x^{3/2}}{3/2}\right]_0^4 = \frac{2}{3} \cdot x^{3/2}\Big|_0^4 = \frac{2}{3} \cdot 8 - 0 = \frac{16}{3}$$

סעיף ב: $\dfrac{16}{3}$ הוא השטח הכלוא בין גרף $f(x) = \sqrt{x}$, ציר ה-$x$ ונקודות $x = 0$ ו-$x = 4$.

## שאלה 7 (בגרות 2024, 5 יחידות — פונקציה קדומה)

**שאלה:** נתון $F'(x) = 6x^2 - 4x + 1$ וכן $F(1) = 3$. מצא את $F(x)$.

**פתרון:**

$$F(x) = \int (6x^2 - 4x + 1)\, dx = 2x^3 - 2x^2 + x + C$$

מתנאי ההתחלה: $F(1) = 2 - 2 + 1 + C = 1 + C = 3 \Rightarrow C = 2$

$$F(x) = 2x^3 - 2x^2 + x + 2$$

# סטטיסטיקה — נוסחאות

## מדדי מרכז

**ממוצע (Mean):**
$$\bar{x} = \frac{\sum_{i=1}^n x_i}{n} = \frac{x_1 + x_2 + \cdots + x_n}{n}$$

**חציון (Median):** הערך האמצעי לאחר מיון. אם $n$ זוגי — ממוצע שני האמצעיים.

**שכיח (Mode):** הערך הנפוץ ביותר.

**ממוצע משוקלל:**
$$\bar{x} = \frac{\sum f_i x_i}{\sum f_i}$$

## מדדי פיזור

**טווח:** $R = x_{max} - x_{min}$

**סטיית תקן (Standard Deviation):**
$$\sigma = \sqrt{\frac{\sum(x_i - \bar{x})^2}{n}}$$

**שונות (Variance):** $\sigma^2$

**מרחק בין-רבעוני (IQR):** $Q_3 - Q_1$

## רביעונים
- $Q_1$: חציון המחצית התחתונה
- $Q_2$: חציון (50%)
- $Q_3$: חציון המחצית העליונה

## ציון תקן (Z-score)
$$z = \frac{x - \bar{x}}{\sigma}$$

מדד כמה סטיות תקן ערך מסוים רחוק מהממוצע.

## ייצוג גרפי
- **היסטוגרמה:** התפלגות תדרים
- **תיבה ושפם (Box Plot):** Min, $Q_1$, $Q_2$, $Q_3$, Max
- **תרשים עוגה:** חלקים מהשלם

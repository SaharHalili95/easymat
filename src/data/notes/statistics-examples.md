# סטטיסטיקה — תרגילים עם פתרון

## תרגיל 1: חישוב ממוצע, חציון, שכיח
הציונים: 72, 85, 90, 85, 78, 92, 85, 70

**פתרון:**
מיון: 70, 72, 78, 85, 85, 85, 90, 92

$$\bar{x} = \frac{70+72+78+85+85+85+90+92}{8} = \frac{657}{8} = 82.1$$

חציון: ממוצע האמצעיים = $\frac{85+85}{2} = 85$

שכיח: 85 (מופיע 3 פעמים)

## תרגיל 2: סטיית תקן
נתונים: 2, 4, 4, 4, 5, 5, 7, 9. חשב ממוצע וסטיית תקן.

**פתרון:**
$$\bar{x} = \frac{40}{8} = 5$$

$$\sigma = \sqrt{\frac{(2-5)^2+(4-5)^2+(4-5)^2+(4-5)^2+(5-5)^2+(5-5)^2+(7-5)^2+(9-5)^2}{8}}$$
$$= \sqrt{\frac{9+1+1+1+0+0+4+16}{8}} = \sqrt{\frac{32}{8}} = \sqrt{4} = 2$$

## תרגיל 3: Z-score
בבחינה: $\bar{x} = 70$, $\sigma = 10$. תלמיד קיבל 85. מה ה-Z-score שלו?

**פתרון:**
$$z = \frac{85 - 70}{10} = 1.5$$

התלמיד נמצא 1.5 סטיות תקן מעל הממוצע.

## תרגיל 4: ממוצע משוקלל
ציון מתמטיקה: 80 (משקל 40%), מדעים: 90 (משקל 35%), עברית: 70 (משקל 25%).

**פתרון:**
$$\bar{x} = 80 \times 0.4 + 90 \times 0.35 + 70 \times 0.25 = 32 + 31.5 + 17.5 = 81$$

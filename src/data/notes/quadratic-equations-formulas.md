# משוואה ריבועית — נוסחאות

## הצורה הכללית
$$ax^2 + bx + c = 0 \quad (a \neq 0)$$

## נוסחת השורשים
$$x_{1,2} = \frac{-b \pm \sqrt{b^2 - 4ac}}{2a}$$

## הדיסקרימיננטה
$$\Delta = b^2 - 4ac$$

| $\Delta$ | מספר פתרונות |
|----------|-------------|
| $\Delta > 0$ | שני פתרונות ממשיים שונים |
| $\Delta = 0$ | פתרון יחיד (שורש כפול): $x = \frac{-b}{2a}$ |
| $\Delta < 0$ | אין פתרונות ממשיים |

## ויאטה — קשר בין שורשים למקדמים
$$x_1 + x_2 = \frac{-b}{a} \qquad x_1 \cdot x_2 = \frac{c}{a}$$

## פירוק לגורמים
$$ax^2 + bx + c = a(x - x_1)(x - x_2)$$

## הפונקציה הריבועית $f(x) = ax^2 + bx + c$

**קודקוד הפרבולה:**
$$x_v = \frac{-b}{2a} \qquad y_v = f(x_v) = \frac{-(b^2 - 4ac)}{4a} = \frac{-\Delta}{4a}$$

**כיוון פתיחה:** $a > 0$ פרבולה פתוחה כלפי מעלה, $a < 0$ כלפי מטה.

**נקודות חיתוך עם ציר $x$:** השורשים $x_1, x_2$ (אם קיימים).

**נקודת חיתוך עם ציר $y$:** $(0, c)$

# סדרות — נוסחאות

## סדרה חשבונית (Arithmetic)
סדרה שבה ההפרש בין כל איבר לקודמו קבוע: $d = a_{n+1} - a_n$

**האיבר הכללי:**
$$a_n = a_1 + (n-1)d$$

**סכום $n$ איברים ראשונים:**
$$S_n = \frac{n(a_1 + a_n)}{2} = \frac{n(2a_1 + (n-1)d)}{2}$$

## סדרה הנדסית (Geometric)
סדרה שבה המנה בין כל איבר לקודמו קבועה: $q = \frac{a_{n+1}}{a_n}$

**האיבר הכללי:**
$$a_n = a_1 \cdot q^{n-1}$$

**סכום $n$ איברים ראשונים:**
$$S_n = \frac{a_1(1 - q^n)}{1 - q} \quad (q \neq 1)$$

**סכום סדרה הנדסית אינסופית** (כאשר $|q| < 1$):
$$S_\infty = \frac{a_1}{1 - q}$$

## קשרים שימושיים
- $a_n = S_n - S_{n-1}$ לכל $n \geq 2$
- ממוצע חשבוני: $b = \frac{a + c}{2}$ (כאשר $a, b, c$ חשבונית)
- ממוצע הנדסי: $b = \sqrt{ac}$ (כאשר $a, b, c$ הנדסית)
